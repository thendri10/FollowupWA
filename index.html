Script Generator

Follow-Up Tracker

Data tersimpan di Supabase kamu sendiri — bisa dilanjutkan dari device manapun, kapan saja. Tahap follow-up dihitung otomatis dari tanggal kontak terakhir.

Unduh semua lead di tracker sebagai CSV, lalu upload/paste ke Google Sheets kamu kapan saja.

Import Data

Google Sheets tidak bisa auto-sambung dua arah. Tapi lead yang kamu import di sini langsung masuk ke database Supabase kamu — bisa lanjut dari device manapun. Untuk kirim balik ke Sheets, pakai tombol Export CSV di tab Tracker.

Susun kolom di Google Sheets seperti ini (urutan kolom, tidak harus pakai header):
Nama | No. WA | Tanggal Kontak Terakhir (YYYY-MM-DD) | Status | Tipe Unit
Status boleh ditulis bebas — misal "sudah tanya", "ghosting", "site visit", nanti dicocokkan otomatis.

Blok sel di sheet → Ctrl/Cmd+C → tempel di bawah ini.

Di Google Sheets: File → Download → Comma Separated Values (.csv)
